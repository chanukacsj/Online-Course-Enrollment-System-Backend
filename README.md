## 📌 Overview
This repository contains the backend API for an **Online Course Enrollment System**.  
It handles core functions such as **user authentication**, **course management**, and **student enrollments**—serving as the server-side foundation of your web application.

---

##  Key Features
-  **User Authentication** (students/administrators): register, log in
-  **Course Management**: create, update, delete, and fetch courses
-  **Enrollment Handling**: enroll and manage student registrations
-  **RESTful API Design** for seamless integration with frontend apps
-  **Optional**: Integration with third-party services (e.g., email notifications, payment gateways)
